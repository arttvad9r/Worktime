# Room schemas

This directory contains the committed Room schema history for the 2026 rewrite database.

`com.worktime.app.modern.data.ModernDatabase/2.json` is generated by Room/KSP during a verified build and is checked for drift in CI. Database version 1 predates committed schema export; the explicit `1 -> 2` migration is covered by an instrumented migration test. Every future database version must keep the previous committed schemas and add migration coverage before release.
