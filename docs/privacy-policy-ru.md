# Политика конфиденциальности WorkTime

Дата вступления в силу: 1 октября 2026 г.

Эта политика описывает, как мобильное приложение WorkTime для Android (пакет `com.worktime.app`, далее — «Приложение») обращается с данными пользователя. Разработчик Приложения — arttvad9r (далее — «Разработчик»).

## 1. Какие данные обрабатываются

Приложение обрабатывает только данные, которые пользователь сам вводит:

- даты рабочих смен и отработанное время;
- часовую ставку, премии и штрафы по каждой смене;
- ставку по умолчанию и выбранную тему оформления.

Приложение не собирает имя, телефон, email, геолокацию, контакты, фотографии, идентификаторы устройства и иные персональные данные.

## 2. Где хранятся данные

Все данные хранятся только на устройстве пользователя, во внутреннем хранилище Приложения. Приложение не имеет разрешения на доступ в интернет, не использует аккаунты, серверы, аналитику, рекламу и сервисы сбора отчётов об ошибках. Разработчик не получает и не хранит копию данных пользователя.

Облачное резервное копирование Android и перенос данных между устройствами для данных Приложения отключены.

## 3. Разрешения

Приложение не запрашивает разрешения на доступ к интернету, геолокации, контактам, камере, микрофону и файлам устройства.

## 4. Экспорт и импорт

Пользователь может по своей инициативе экспортировать данные в файл (JSON или CSV) или импортировать их из файла. Место сохранения и файл для импорта пользователь выбирает сам через системное окно выбора файлов Android. Если пользователь сохраняет файл в облачное хранилище или передаёт его другому приложению, такая передача происходит по его выбору и регулируется правилами соответствующего сервиса.

## 5. Передача третьим лицам

Разработчик не передаёт, не продаёт и не раскрывает данные пользователя третьим лицам, так как не получает их.

## 6. Удаление данных

Пользователь может удалить любую запись в Приложении. При удалении Приложения с устройства все его данные удаляются. Экспортированные файлы находятся вне Приложения и удаляются пользователем самостоятельно.

## 7. Дети

Приложение не предназначено специально для детей и не собирает сведения о возрасте пользователей.

## 8. Изменения политики

Если в новой версии Приложения изменится порядок обработки данных, эта политика будет обновлена до выхода такой версии. Актуальная редакция публикуется по этому адресу.
