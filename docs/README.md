# WorkTime rewrite documentation

These documents describe only the implementation on `rewrite/worktime-2026`.

- `ARCHITECTURE.md` — actual runtime, state, persistence and navigation structure.
- `MODERNIZATION_STATUS.md` — what is implemented, what automated CI proves, and what is still a release gate.
- `PRIVACY.md` — current local-data and permission model.
- `RELEASE_CHECKLIST.md` — gates required before the rewrite can replace the published app.
- `RELEASE_SIGNING.md` — production signing procedure and update identity.

Documentation, screenshots, plans and benchmarks from the rejected implementation are intentionally not retained in this branch as current design evidence. Git history is the reference source when historical comparison is needed.
